# Strong & Steady — Beginner Training Plan

A small, responsive static website for the beginner gym routine. It uses plain HTML, CSS, and JavaScript, so there is no build step or package install.

This personalized edition is styled for Mikaela Jae Guinto and features her favourite verse, Psalm 46:5.

## Run it locally

Open `index.html` in a browser. Exercise demos are embedded from YouTube's privacy-enhanced player and can also be opened on YouTube from each card.

## Add it to a GitHub repo

Copy `index.html`, `styles.css`, `app.js`, and `README.md` into the repo. To publish with GitHub Pages, open the repository's **Settings → Pages**, choose **Deploy from a branch**, then select the branch and `/ (root)` folder containing `index.html`.

## What's included

- Monday–Saturday routine, plus a Sunday recovery day
- Two strength workouts, with Friday alternating A/B by week
- Individual demo videos, form cues, sets, reps, and beginner-friendly swaps
- Browser-saved exercise checkmarks
- Flexible calorie and macro starting estimates with Filipino-friendly meal ideas
- Mikaela's Psalm 46:5 favourite verse and original weekly reminders
- ChatGPT question handoff: copies the question with plan context and opens ChatGPT; no API key is stored in the website
- Links to general adult activity guidance, protein and resistance-training research, and Anytime Fitness Philippines

## Notes

The exact equipment available at an individual Anytime Fitness club can vary. Ask the club's floor staff to demonstrate machine adjustments and help choose comfortable starting weights. Nutrition figures are broad estimates, not a clinical prescription.
